# 通用收银台 · 多端同步服务器

让**手机、平板、收银机、电脑**看到同一份商品 / 会员 / 订单。
零依赖（只用 Node 内置模块），数据存在你自己这台电脑上，不走任何第三方云。

---

## 零、先看这里：桌面版不需要手动启动

如果你装了**桌面版收银台**（Windows / macOS / Linux 安装包），它**启动时会自动跑好这个服务**，
默认 `http://localhost:8787`，端口被占用会自动顺延（8788、8789…），实际地址会显示在
「设置 → 账号登录与多端同步」的绿色状态卡里。

这种情况下本文档剩下的部分你**都不用做**。

只有下面两种情形才需要手动启动：

1. 你只用**手机 / 网页版**，手边那台电脑没装桌面版收银台；
2. 桌面版面板显示「本机同步服务启动失败」（比如 8787–8792 端口全被别的软件占了）。

> **重要（v1.5.1 起）：这个服务器只负责「多端同步」，「账号登录」本身完全不需要它。**
> 手机号 / 邮箱 + 密码是在**本机**注册和校验的，第一次点「登录」就自动建号，
> 断网、单机、没装 Node 都能用。服务器只在你**想让多台设备看到同一份数据**时才需要。
> 所以下面做不做，取决于你要不要多端同步。

## 一、手动启动：三步用起来

### 第 1 步：在这台电脑上启动服务器

先装 Node.js（只需装一次）：

- 打开 <https://nodejs.org> ，下载 **LTS** 版本，一路「下一步」装完即可。
- 装完关掉所有命令行窗口，再继续。

然后启动：

| 系统 | 怎么做 |
|---|---|
| **Windows** | 双击 `启动同步服务器.bat` |
| **macOS** | 双击 `启动同步服务器.command`（若提示「无法打开」，右键 →「打开」→「打开」） |
| **Linux** | 终端里执行 `./start.sh` |

看到这样的输出就成功了：

```
  ╔══════════════════════════════════════════════════════╗
  ║        通用收银台 · 多端同步服务器 已启动            ║
  ╚══════════════════════════════════════════════════════╝

  本机地址（这台电脑上打开收银台就填这个）：
      http://localhost:8787

  局域网地址（手机 / 其他电脑连同一个 WiFi 就填这个）：
      http://192.168.1.5:8787
```

> **这个窗口不要关。** 关掉窗口 = 停止同步服务（已经同步过的数据不会丢，只是暂时连不上）。

### 第 2 步：第一台设备注册账号

有两个入口，效果完全一样：

- **打开应用时的登录界面** → 展开最下面的「多端同步（可选）」→ 填账号 + 密码 → 点「**注册新账号**」（v1.5.2 起登录界面只剩这一个）
- **设置 → 账号登录与多端同步** → 展开「多端同步（可选）」→ 填账号 + 密码 → 点「**注册并登录**」

不管哪个入口：

1. 同步服务器地址已经自动填好了（独立部署时填 `http://localhost:8787`，就是当前这台电脑）
2. 填**手机号**（`13800001234`）**或邮箱**（`you@example.com`），加密码（至少 6 位）
3. 点注册

> **v1.5.1 起更省事**：其实直接点「**登录**」就行 —— 本机没有这个账号时，
> 收银台会先问服务器，服务器上也没有就在本机建号，并自动在服务器上同步建好。
> 不用先想清楚「该点注册还是登录」。

> **手机号和邮箱完全等价**，随便用哪个当账号都行。
> `13800001234`、`+8613800001234`、`138-0000-1234` 会被当成同一个账号，
> 所以不用担心写法不一致登不上去。同一个手机号 / 邮箱也不会被重复注册。
> 旧版本（v1.4.x）只用邮箱注册的账号不受影响，原来怎么登现在还怎么登。

登录后本机已有的商品、会员、订单会自动上传。

### 第 3 步：其他设备用同一个账号登录

手机上打开同一个收银台，**打开应用时的登录界面**（或 **设置 → 账号登录与多端同步**）：

1. 「同步服务器地址」填服务器窗口里那个**局域网地址**，例如 `http://192.168.1.5:8787`
2. 填**同一个账号 + 同一个密码**
3. 点 **登录**

登录后会自动把云端的商品、会员、订单拉下来。之后任何一台设备改了数据，4 秒内自动同步到其他设备。

## 二、几个常见问题

**手机上提示连不上服务器？**

- 手机和这台电脑必须在**同一个 WiFi**下（不能一个连 WiFi、一个用 4G）。
- 确认服务器窗口还开着。
- 确认地址里的 IP 是**服务器窗口显示的那个**（换网络后 IP 会变，重新看一眼即可）。
- Windows 第一次启动会弹防火墙提示，要选 **允许访问**。

**换网络后手机连不上了？**

路由器重新分配了 IP。看服务器窗口里新的局域网地址，在手机上改掉「同步服务器地址」再点「保存地址」。

**能在外网（不同网络）同步吗？**

可以，但需要把 8787 端口映射到公网（路由器端口转发，或内网穿透工具如 frp / ngrok / 花生壳），
然后用映射后的地址。**注意**：一旦暴露到公网，请务必使用强密码。

**数据存在哪里？**

`sync-server/data/db.json`。这是纯文本 JSON，可以直接复制走做备份，也可以随时搬去别的电脑。

**密码安全吗？**

密码用 PBKDF2-HMAC-SHA512 + 每个账号独立的随机盐加密存储（12 万次迭代），数据库里**没有明文密码**。
登录成功后会发一个 30 天有效的令牌给客户端。

**服务器能换电脑吗？**

可以。把整个 `sync-server` 文件夹（含 `data`）拷到新电脑，在新电脑双击启动，各端把地址改成新电脑的地址即可。

## 三、接口一览（排查问题时用）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 健康检查，返回服务名与已注册账号数（无需登录） |
| POST | `/api/register` | 注册并返回令牌 `{account, password, shopName}`（account 为手机号或邮箱） |
| POST | `/api/login` | 登录并返回令牌 `{account, password}`（account 为手机号或邮箱）。**账号不存在返回 `404`，密码错返回 `401`** —— 客户端据此决定是提示密码错，还是在本机新开一个同名账号 |
| POST | `/api/logout` | 注销当前令牌 |
| GET | `/api/me` | 当前账号 + 云端数据版本号 |
| GET | `/api/shop` | 拉取整店数据 |
| PUT | `/api/shop` | 推送整店数据，带 `rev` 做乐观并发；版本落后返回 `409` |
| GET | `/api/orders?since=N` | 增量拉取订单（`N` 为本机已知最大版本号） |
| PUT | `/api/orders` | 按 `order_uid` 幂等上推订单 |

自测：浏览器打开 <http://localhost:8787/health>，看到 `"ok":true` 即正常。

## 四、同步行为说明

- **整店数据**（店铺设置、商品、会员、库存流水、短信记录、交班、挂单）
  走 `rev` 版本号做乐观并发控制。拉取时按「**本机优先**」合并：
  两边都有的记录保留本机版本（本机改动不会被抹掉），云端独有的记录会追加进来。
- **订单**走独立的增量通道，按 `order_uid` 幂等 upsert，只增不改，
  不会因为整店覆盖把别端刚开的单冲掉。
- **改动后 4 秒**自动同步一次（防抖），也可以在设置里点「立即同步」。
- **离线时**照常收银，数据先存本机；联网后自动补传。没登录账号也不会影响任何收银功能。
- **多账号互相隔离**：每个账号只能看到自己的数据，服务器的每个接口都强制校验归属。
