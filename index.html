如何真实下发短信？（腾讯云 / 阿里云 对接示例）
浏览器出于安全限制，无法直接调用短信厂商 API（跨域 + 密钥会暴露）。 请用云函数做一层转发：本应用把短信内容 POST 给你的 Webhook，云函数再调用腾讯云/阿里云短信接口下发。
// 腾讯云云函数（Node.js）示例
const tencentcloud = require("tencentcloud-sdk-nodejs-sms");
const SmsClient = tencentcloud.sms.v20210111.Client;

exports.main_handler = async (event) => {
  const body = JSON.parse(event.body || "{}");
  const client = new SmsClient({
    credential: { secretId: process.env.SECRET_ID, secretKey: process.env.SECRET_KEY },
    region: "ap-guangzhou", profile: { httpProfile: { endpoint: "sms.tencentcloudapi.com" } }
  });
  const res = await client.SendSms({
    PhoneNumberSet: ["+86" + body.phone],
    SmsSdkAppId: "1400000000",        // 你的 SdkAppId
    SignName: body.sign || "你的签名",  // 需在腾讯云备案通过
    TemplateId: "1234567",            // 你的模板 ID
    TemplateParamSet: [body.content]  // 模板里用 {1} 接收整条内容
  });
  return { statusCode: 200, body: JSON.stringify(res) };
};

// 本应用发出的请求体格式：
// {
//   phone: "13800000000", sign: "我的店铺", templateCode: "",
//   content: "【我的店铺】张先生您好，您的会员卡已开通…",
//   vars: { 店铺:"我的店铺", 姓名:"张先生", 卡号:"VIP000001", 金额:"68.00", … },
//   shop: "我的店铺", type: "open"
// }

使用帮助

快速开始
1) 设置 → 填入店铺名称、上传 Logo、选好货币与税率。
2) 商品管理 → 新增商品（名称/条码/分类/单价/库存）。
3) 收银台 → 点商品或扫码加购 → 选支付方式 → 完成。

快捷键
收银台：F1 现金 / F2 微信 / F3 支付宝 / F4 银行卡 / F6 卡余额 / F9 组合支付；扫码框输入条码按 Enter 加购。

卡余额支付
先在上方「选择会员」里选中会员， 收银台会出现「卡余额」按钮（会员余额为 0 时不可点）。
· 余额够：点「卡余额」直接付清。
· 余额不够：会提示差额，确认后可先在「组合支付」里手动填写每种方式各收多少。
· 用现金/微信等收款时，也会问你要不要先用卡余额抵扣一部分。

支付方式开关
设置 → 收银台支付方式，可手动勾选收银台要显示哪几种收款方式（含卡余额与组合支付）， 关掉的不显示；至少要留一种。

库存无限
商品管理 → 新增/编辑商品 → 勾选「库存无限」，该商品就不记库存了： 收银台随便卖（不显示缺货）、结算不扣库存、不进低库存预警与盘点清单，入库按钮也会置灰。
适合服务、话费充值、随意量商品，或从 Excel 导入时来源表根本没有库存列的情况 （导入时「新商品若来源没有库存列」默认就是「库存无限」）。取消勾选即恢复按数字库存管理。

挂单 / 取单：店内忙时点「挂单」把当前购物清单暂存（可写备注如「3号桌」）， 闲下来点「取单」挑一条继续结算。挂单内容与会员、优惠一并保存。

促销与优惠：结算金额按「满减 → 会员等级折扣 → 整单优惠 → 抹零」依次计算， 明细在购物车右侧逐行显示。满减规则、抹零方式在「设置 → 促销与优惠」配置，一行一条（如 满100减10）。

会员等级：按会员累计消费自动升级并享受对应折扣（如银卡 95 折）。 等级表在「设置 → 会员等级与折扣」配置，格式 等级名,消费门槛,折扣率%，一行一条。

员工与权限：设置页可添加收银员账号并启用登录。店长可管理商品、员工与清空数据； 收银员仅可收款。勾选「仅店长可修改整单优惠」后，收银员无法随意打折。

会员：会员消费累计积分，可用余额抵扣；设置页可充值。设置页各工具段可点标题折叠收起（右上角可全部展开/收起）。

消费开卡：收银台输入顾客姓名或手机尾号即可自动识别老会员（输完整手机号也行）；未开卡时点「🎫 消费开卡」现场发卡， 可设开卡礼金与赠送积分，开卡后本次消费自动计入该会员。门槛、赠积分倍数、卡号前缀在「设置 → 会员卡」配置。

短信通知：开卡、消费、充值后可自动给顾客手机号发短信。默认「本地记录」通道仅作演示不入网； 需要真实下发时，在「设置 → 短信通知」填入自己的 Webhook 地址（转发到腾讯云/阿里云短信）， 设置页内有云函数示例代码。

交班：报表页「交班结算并打单」汇总本班营收并留存记录。

数据备份：设置 → 导出全部数据（换设备/清缓存前务必导出）；可导入恢复。

部署预置：在程序目录放 store.json（{"name":"店名","logo":"data:image/png;base64,..."}）可一次性预置店铺名与 Logo。
